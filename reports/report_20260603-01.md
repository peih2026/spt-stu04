## 新発見：XSS脆弱性（クロスサイトスクリプティング）7ヶ所

| # | ファイル | 行 | コード | リスク |
|---|---------|-----|-------|-------|
| X1 | order_list.jsp | 19 | `<%= request.getParameter("customerNm") %>` | 検索条件に`<script>を挿入可能 |
| X2 | order_list.jsp | 21 | `<%= request.getParameter("dateFrom") %>` | 同上 |
| X3 | order_list.jsp | 22 | `<%= request.getParameter("dateTo") %>` | 同上 |
| X4 | order_list.jsp | 53 | `<%= customerNm %>` | DBの取引先名にスクリプト混入で発火 |
| X5 | order_list.jsp | 62 | `<a onclick="...orderNo=<%= orderNo %>"` | URLパラメータ経由のXSS |
| X6 | inventory.jsp | 37 | `<title>在庫一覧 - <%= warehouseCd %></title>` | パラメータ経由でスクリプト注入 |
| X7 | inventory.jsp | 54-57 | `out.println(e.getValue())` | ISSUE-217として認識済み |

**根本原因**: JSPでユーザ入力値を `<%= ... %>` で直接出力しており、`escapeXml` / `c:out` 等のエスケープ処理がない。

**改善措置**: JSTLの `<c:out value="..." />` または `fn:escapeXml()` を使用してHTMLエスケープを行う。

## GitHub Issues — 根因と対策（重点）

- **Issue #13 — [TICKET-ASTR-024] customer_master_sync 実行後に退会済み顧客が有効として復活する**
	- 根因: ETL が上書き処理（full-replace）またはマージ時に退会フラグを考慮していないため、上流のデータで削除済みレコードが復元される。
	- すぐの対策: ETL の書き込み前に退会/削除フラグを確認し、削除済レコードは上書きしない（skip）処理を導入する。
	- 推奨修正: 差分更新（キー＋タイムスタンプ）によるマージロジックを実装し、退会フラグを最優先の保護ルールとして扱う。ETL のテストケースに退会ケースを追加。

- **Issue #12 — [ISSUE-233] 受注登録を続けると「接続が取得できません」で全画面が停止する（静的 Connection 共有）**
	- 根因: `DBUtil` 等で `static` な Connection を共有しており、接続の適切な取得/解放がされないため接続枯渇や例外が発生する。
	- すぐの対策: デプロイ側で接続プール（または再起動）による復旧運用を行い、監視アラートを設定する。
	- 推奨修正: 全ての static Connection を廃止し、DataSource／接続プール（例: HikariCP/Tomcat pool）を利用、`try/finally` で必ず `close()` する実装に置換する。接続取得失敗時のリトライやタイムアウトも導入。

- **Issue #11 — [ISSUE-211] 倉庫を切り替えると在庫数が別倉庫の値のまま表示される**
	- 根因: キャッシュ鍵やクエリパラメータの取り扱いミスにより、倉庫IDで結果を分離できていない可能性が高い。
	- 修正案: キャッシュキーに倉庫IDを含めるか、倉庫切替時にキャッシュを無効化する。クエリのパラメータバインディングを確認し、ユニットテストで倉庫切替シナリオを追加する。

### 共通対策（短期〜中期）

- 短期（即日〜数日）: 監視とアラートの強化（DB接続エラー、エラー率の増加、主要APIの応答遅延）。重要箇所の追加ログ出力で原因追跡を容易にする（※ただし機密情報は出力しない）。
- 中期（1〜2週）: コード修正（static Connection の除去、差分マージの導入、JSP の HTML エスケープと SQL パラメータ化）。`LoginServlet` の MD5 を PBKDF2/BCrypt/Argon2 等に置換。
- 長期（数週〜数月）: CI に SAST/静的解析（FindSecBugs/SpotBugs 等）と自動回帰テスト、負荷試験を導入し、セキュリティと品質ゲートを設定する。
